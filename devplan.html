Project Description (Stage 1)

waNDer

A collaborative travel-planning tool with shareable boards, top-rated site suggestions, map routing, and a "mapped" yearly summary of your trips.

Stage 2 — Development Plan

Tech Stack & Data

Database: MySQL via db8.nd.cse. Frontend: PHP + HTML. Advanced functions: Python.

Data source: Yelp Open Dataset — free for academic use, 11 cities, 4 chosen: Edmonton (Alberta), Tucson (Arizona), Indianapolis (Indiana), Tampa (Florida). May be trimmed if data volume is too high.

Schema

Boards (
	board_id int primary key,
	title char(50),
	destination char(30),
	time_created datetime,
	collaborator_ids int
)

Have (
	Boards.board_id int primary key,
	Markers.name char(50) primary key,
	Markers.addr char(50) primary key
)

Markers ( 
	name char(50) primary key,
	addr char(50) primary key,
	category char(50), 
	rating int
)

Reviews (
	review_id int primary key,
	Users.user_id int foreign  key,
	Markers.name char(50) foreign key,
	Markers.addr char(50) foreign key,
	text varchar(300)
)

Interests(
	Users.user_id int primary key foreign key,
	interest_name char(50) primary key,
	rank int 
)

Users(
	user_id int primary key, 
	name char(50), 
	email char(50),
	password char(50)
)

Choose(
	Users.user_id int primary key, 
	Interests.interest_name primary key
)
Create (
	Boards.board_id int primary key,

)

Suggest(
	Markers.name char(50) primary key,
